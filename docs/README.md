# Documentation map

## Current implementation

- `implementation_decisions.md`: official runtime target, clean-room
  reconstruction boundary, validation gates, and licensing posture.
- `data_inventory.md`: locally verified source files, schemas, counts, and
  integrity results.
- `agent_handoff.md`: detailed narrative of the most recent work session
  (what was tried, what broke, what was fixed, what's still in progress) -
  read this for context before continuing prior work. See also
  `../CLAUDE.md` (project root) for the short-form version, and
  `../experiments/improvements/README.md` for the version-by-version
  scoreboard and the lessons that generalize.

## `competition/`

Reference material supplied for this competition:

- `Trace_the_Ace_full_overview.md`: task, public schema description, metric, and competition context.
- `competition_rules.md`: participation, data-use, licensing, and test-independence rules.
- `code_submission_format.md`: inference filesystem, ZIP structure, output schema, and runtime limits.
- `example_documentation_guide.pdf`: finalist reproducibility and write-up guidance.

## `history/`

Imported records from a prior implementation. They contain valuable verified findings and experiment history, but claims about existing scripts, caches, models, submissions, and leaderboard status do **not** describe the current repository unless independently reconstructed and validated here.
